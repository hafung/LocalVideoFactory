# 声织 VoxWeave 自动成片产品方案

> 状态：已确认方向，作为 v0.3+ 产品边界与验收依据。

## 1. 产品定义

声织不是通用剪辑器，而是面向电商推广、广告和观点输出的本地优先自动成片工具。它服务于不愿真人露脸口播，或者希望快速批量生产短视频的创作者。

用户的最小输入只有文案。原始视频是可选输入；没有原视频时，系统使用本地素材库中的 B-roll、图片、动态图形和字幕完成整条视频。

产品承诺是：

> 输入文案和可选原视频，自动得到一条可直接发布、也可以低成本换素材或换风格的视频。

## 2. 用户流程

首版只暴露一个主要流程：

1. 输入文案。
2. 可选添加一段或多段原始视频。
3. 选择画幅、音色、字幕风格、画面风格和可选 BGM。
4. 点击“生成视频”。
5. 查看预览；必要时执行“换这个画面”“换一组素材”“换字幕风格”或“重新生成”。
6. 导出 MP4，并可选导出 SRT/ASS。

不向普通用户暴露多轨时间线、关键帧、滤镜图或 FFmpeg 参数。后续若需要人工干预，使用按语义段组织的“分镜卡片”，而不是传统剪辑器界面。

## 3. 自动成片原则

### 3.1 旁白是主时钟

TTS 的真实音频时长决定视频时长。系统先生成分句旁白，再确定字幕和画面切换时间，不能仅依赖文字字数提前锁死时间线。

### 3.2 原始视频只是优先素材

- 有原始视频时，优先使用其中质量合格的区间。
- 单个画面连续时间过长时插入 B-roll，降低单调感。
- 原始视频短于旁白时，用 B-roll、图片推拉或动态图形补齐，不拉伸和机械循环原视频。
- 没有原始视频时，整条视频由 B-roll、图片、品牌模板和动效字幕组成。
- 原视频长于旁白时，先检测镜头边界和黑场，从全片按原有顺序选取片段，精确覆盖旁白时长；不只保留开头，也不通过整体加速硬压时长。无原片转写或画面描述时，这属于按镜头结构编排，不能保证语义上的精彩片段选择。
- 自动补画面优先使用视频，允许多条短视频拼接；视频不足时，每张图片默认不超过 2 秒，不用一张图片撑满长段落。
- 开启原声时，原声使用与原片选段一致的入点、出点和时间轴；替换画面保留这条已剪辑原声音轨，原片用完后不循环原声。
- 只自动去除高置信度问题，如黑帧、长静音、明显冻结；主观“废镜头”不作为首版能力。

### 3.3 B-roll 是受约束的检索与编排

系统按句子或语义片段创建画面插槽，为每个插槽生成检索意图，并结合以下因素选择素材：

- 文案关键词和标签相关度；
- 横竖屏、分辨率与可裁切性；
- 素材时长；
- 同一素材的重复惩罚；
- 来源与授权状态；
- 原始视频优先级。

检索失败时，必须有稳定兜底：主题背景、商品图片推拉、强调文字或抽象动态图形。

## 4. 字幕体验

中文文案由 jieba 精确分词，并允许维护电商、品牌和专有名词词典。SenseVoice 负责从生成后的音频提取声学 token 时间，系统再把识别 token 与已知原文对齐，将时间映射回 jieba 词组。

成品字幕不依赖 SRT 表现动效。内部使用逐 token 的 caption 数据，由渲染器实现逐词变色、缩放或词组切换；SRT/ASS 只是额外导出格式。

首版字幕模板：

- 电商强调：关键词双色和轻微放大；
- 观点口播：底部两行逐词高亮；
- 品牌极简：居中短词组；
- 信息卡片：标题、正文、要点分层。

所有模板必须处理安全区、最大行宽、断行、描边、对比度和 `prefers-reduced-motion`。

## 5. 素材库

素材库由用户人工维护，并由系统自动补充元数据。媒体文件保留在文件系统，数据库只保存索引和派生信息。

导入时自动执行：

1. ffprobe 读取时长、尺寸、帧率、音轨和编码；
2. 内容指纹去重；
3. 生成缩略图、关键帧和预览代理；
4. 视频镜头切分；
5. 可选语音转写；
6. 从文件名、目录、转写和人工输入生成初始标签；
7. 写入全文索引。

首版使用标签、jieba 关键词和 SQLite FTS5/BM25。CLIP 类语义向量检索延后到素材规模和真实检索数据证明有必要时再加入。

## 6. EditPlan 是产品协议

VoxWeave 持久化版本化的 `EditPlan JSON`，而不是 HyperFrames HTML、Remotion JSX 或 FFmpeg 命令。EditPlan 包含输入、旁白、分镜、字幕、素材选择、BGM 和输出设置。

生命周期：

- `draft`：完成文案分段和素材检索意图；
- `resolved`：TTS、字幕对齐和素材选择完成，所有时间已确定；
- `rendering`：渲染中；
- `complete`：成品可用；
- `error`：保留可恢复错误信息。

每个已选择素材同时保留 `assetId` 和原始检索意图。前者保证重现，后者支持一键换素材。

## 7. MVP 范围

### 必须完成

- 文案和可选原始视频输入；
- 9:16、16:9、1:1；
- 本地 Qwen3-TTS 旁白；
- SenseVoice 中文对齐；
- jieba 逐词/词组字幕；
- 本地图片、视频、BGM 素材库；
- 标签与全文自动检索；
- 自动 B-roll 编排；
- 4 套受控模板；
- BGM 混音、人声闪避、响度标准化；
- 预览、取消、失败恢复和 MP4 导出；
- 单分镜换素材。

### 明确不做

- 通用多轨剪辑器；
- 自由关键帧和复杂特效面板；
- 对人物表现和内容正确性的主观废镜头判断；
- 强制云端账号或上传用户素材；
- 首版在线版权素材商城；
- 光流补帧和慢动作增强。

## 8. 成功指标

- 80% 的测试文案无需编辑即可形成结构完整的视频；
- 逐词字幕在人声正常区间内没有肉眼明显漂移；
- 素材不满意时，两次操作内可替换当前分镜；
- 60 秒 1080p 视频可在目标 Windows 设备上稳定完成，不因界面关闭或刷新丢失工程；
- 相同 resolved EditPlan、素材和版本产生可重复的视频；
- 所有素材在导出前具有可追踪的来源和授权字段。

## 9. 风险与边界

- 浏览器逐帧渲染的速度、峰值内存和临时磁盘必须通过 60 秒竖屏样片验证。
- ASR 的 token 不是中文词，必须与已知原文对齐后再按 jieba 聚合。
- SRT 不表达逐词动画；逐词字幕必须由渲染器绘制。
- HyperFrames 更新频繁，必须精确锁版本并通过 renderer adapter 隔离。
- FFmpeg、模型、字体、BGM 和内置素材必须分别维护许可证与来源清单。

### 原片与旁白时长适配

用户提供原视频时，在本机分析抽帧和带时间的语音转写，按旁白内容选择原片片段；原片过长时优先保留相关、清晰且动作/语句完整的区间。原片不足、内容不匹配或完整片段放不下的时长，优先自动补视频，图片每张最多 2 秒。原声随实际入出点剪辑。分析失败会显示提示并补充素材；视觉抽帧与语音识别的误差仍需通过原片效果验收。
