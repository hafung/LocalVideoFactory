# LocalVideoFactory v0.2.10

- **口播精剪**：导入真人口播视频，保留原声，整理长停顿和口头语、校正字幕并添加重点画面。新增人声增强，可试听后应用到工程。支持 MP4、SRT 和 ASS 导出。
- **复用手动下载的模型**：修复 Windows 安装包配置本地模型后仍被首启检查拦住的问题。打开「文案成片」，点击「导入本地模型」，选择已有的 `resources` 文件夹。文件通过校验后会写入模型缓存，完整模型可断网导入。
- **下载和报错提示**：首启下载使用系统代理设置，失败时会显示「模型准备失败」及出错的文件。

下载 Windows x64 安装包 `VoxWeave-Setup-0.2.10-x64.exe`。首次在线准备约需下载 9 GB。已下载的模型可复用，Qwen3.5-4B 和视觉投影仍按需单独准备。[构建与离线部署指南](https://github.com/hafung/LocalVideoFactory/blob/v0.2.10/docs/building.md)
