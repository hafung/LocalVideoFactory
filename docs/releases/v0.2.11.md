# 帧舟 FrameSkiff v0.2.11

- **新名称与图标。** 应用现名为帧舟 FrameSkiff，升级后可继续使用已有工程、音色和模型缓存。
- **更快开始创作。** 普通 Windows 安装包首次启动准备约 4.8 GB 的配音与字幕模型。下载可以在后台继续，也可以导入已下载的模型。
- **创作功能按需启用。** 智能分镜与原片选段、本地素材搜索和音色克隆可以在应用里下载。每项功能都有用途说明、准备状态与进度。
- **两种模式共用素材库和设置。** 文案成片和口播精剪的公共入口都在顶部右侧。窗口和 Windows 安装包使用新图标。
- **缺少 Pexels 密钥也能补素材。** 素材库提供 Pixabay 网页入口，下载后可在同一页导入。

下载本页的 `FrameSkiff-Setup-0.2.11-x64.exe` 安装 Windows x64 版，`.sha256` 文件可用于校验。 [源码构建与模型说明](https://github.com/hafung/LocalVideoFactory/blob/v0.2.11/docs/building.md)
