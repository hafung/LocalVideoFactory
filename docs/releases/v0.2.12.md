# 帧舟 FrameSkiff v0.2.12

- **在线素材有更多来源。** Pexels、Pixabay、Coverr 和 Wikimedia Commons 共用搜索、预览和入库流程。没有 API Key 也能使用 Wikimedia Commons。入库时会保存作者、许可和来源，创作设置可查看各来源支持的用途。
- **更方便地换画面。** 在分镜里比较本地和在线素材，预览后应用，也可以让后续几句台词共用一个画面。
- **在素材卡片里直接编辑标签。** 单条素材可在卡片或预览里编辑人工标签。多选时可给勾选的素材一起添加新标签。

- **导出发布包。** 文案成片和口播精剪都可以一次保存 MP4、封面和发布文案。支持从成片换封面帧，编辑和复制发布文案。
- **从口播提取精彩片段。** 启用本地分镜模型后，可以按发布目的生成待试听的候选，也可以手动添加和调整片段，独立导出选中的内容。
- **口播画幅与取景。** 支持竖屏、横屏和方形，可以保留完整画面，也可以填满画幅并手动调整位置。发布包提供针对常用平台的推荐画幅与封面预设。

下载本页的 `FrameSkiff-Setup-0.2.12-x64.exe` 安装 Windows x64 版。可用随附的 `.sha256` 文件核对下载。
