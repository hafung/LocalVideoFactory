# 帧舟 FrameSkiff v0.2.13

- **修复 Windows 10 字幕模型解压失败。** SenseVoice 字幕模型改为单文件直下并保留 SHA-256 校验与断点续传，不再依赖系统自带 `tar.exe` / `bzip2`，解决部分 Windows 10 环境报 `unable to run program "bzip2 -d"` 的问题（#2）。
- **自定义模型存储位置与一键迁移。** 首次准备模型前会展示当前目录和磁盘剩余空间，可直接改选非系统盘目录后再下载；在「创作设置 → 模型存储与国内下载源」中支持跨盘一键迁移已有模型并自动校验清理旧目录。
- **支持国内高速镜像源。** 新增 **HF-Mirror（`hf-mirror.com`）** 与 **魔搭社区 ModelScope（`modelscope.cn`）** 下载源切换，下载过程中切换线路会自动续传，镜像异常时自动回退备用源。
- **支持接入本地 / 外部 OpenAI 兼容 TTS API。** 在「创作设置」中可直接接入 [AudioCpp-Desktop](https://github.com/sipeter/AudioCpp-Desktop)、[qwentts.cpp](https://github.com/Panda-Panta/qwentts.cpp)（`tts-server`）等 `/v1/audio/speech` 服务，支持一键测试连接与拉取音色列表；启用后无需下载 4.5 GB 内置旁白模型，老旧 CPU 或 2–4 GB 显存设备也能流畅配音。

下载本页的 `FrameSkiff-Setup-0.2.13-x64.exe` 安装 Windows x64 版。可用随附的 `.sha256` 文件核对下载。
