# LocalVideoFactory v0.2.8 · 本地 AI 短视频工厂

从文案到成片：自动配音、对齐字幕、检索素材并剪辑视频。仓库现名为 **LocalVideoFactory**，桌面应用与安装包继续沿用 **声织 VoxWeave** 标识，兼容已有工程和音色。

## 相比 v0.2.1 的主要更新

- **自动成片与素材检索**：按真实旁白时长组织分镜，优先选择本地或 Pexels 视频，再以短时图片和动态文字补齐画面。
- **原片智能选段**：结合抽帧画面、原片语音和动作边界匹配旁白，避免机械循环原片；找不到匹配片段时补充其他素材。
- **本地配音与声音克隆**：使用 Qwen3-TTS 1.7B，支持可复用音色与分段旁白合成。
- **动态字幕与分镜精修**：支持词或短语高亮、四种字幕风格、字幕分组，以及按卡片更换画面与选段。
- **免费音乐检索与混音**：通过 Openverse 搜索、试听和入库音乐；旁白、原声、BGM 独立音量，支持背景声音自动压低。
- **多格式导出**：MP4、MP3、SRT、ASS，画面、字幕和音频同步变速。
- **项目展示**：新增真实成片有声演示与中文项目介绍文章。
- **Windows CI 修复**：字幕分组样例同时兼容 LF 与 CRLF 换行，解除 Windows 测试对安装包发布的阻断。

## 下载与首次运行

下载本页附件中的 **`VoxWeave-Setup-0.2.8-x64.exe`**。对应 `.sha256` 文件用于校验安装包完整性。

- 面向 **Windows x64**；核心 AI 使用本机 CPU，当前配音引擎要求 CPU 支持 **AVX2 / FMA**，无需独立显卡。
- 这是**首次启动下载模型的安装包**，首次使用需联网下载约 **9 GB** 语音与检索模型，支持进度、断点续传和 SHA-256 校验。
- **AI 分镜及原片理解模型需另行准备**：Qwen3.5-4B 与匹配的视觉投影不在首启下载清单内。源码环境可执行 `pnpm setup:scene-model`；安装包用户可在设置中选择已下载的模型，并将匹配的 `mmproj-F16.gguf` 放在同目录。详见[模型准备说明](https://github.com/hafung/LocalVideoFactory/blob/v0.2.8/docs/building.md#本地模型与运行时)。
- Pexels 在线画面搜索需要配置 API Key；Openverse 音乐搜索无需 Key，默认 CC0，素材许可信息随记录保存。
- 模型与本地素材准备好后，可以离线完成核心创作流程。耗时和内存需求取决于所选模型、文案与原片长度。
