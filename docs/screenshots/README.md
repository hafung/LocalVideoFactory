# 截图与演示素材

这些截图由当前源码构建的 Windows Electron 应用直接截取，展示真实生成的演示工程。

- `studio.png`：创作工作台、成片预览与分镜卡片。
- `captions.png`：生成后的字幕分组编辑。
- `music.png`：通过 Openverse 实际下载入库的音乐及其许可、来源和署名详情。
- `audio.png`：下载音乐后应用 BGM 的音轨设置。

演示文案为“一段文案，自动变成一条短视频。旁白、字幕和画面，跟着声音同步。你的创意，留在自己的电脑里。”，配音使用内置 Vivian 音色，通过本地 Qwen3-TTS 实际合成。

示例城市航拍画面来自 [Pexels 图片 1642125](https://www.pexels.com/photo/1642125/)，遵循 [Pexels License](https://www.pexels.com/license/)，为演示制成视频片段。截图不包含原图的单独再发行文件。

音乐搜索通过 Openverse 进行，音乐以结果中的作者、来源和许可为准；截图中的来源链接可在应用内查看。示例使用 CC0 音乐，应用会将曲目作者、来源 URL、许可 URL 和署名文本写入本地素材记录。

界面中的“声织 / VoxWeave”是保留兼容的桌面应用名称；GitHub 项目名为 LocalVideoFactory。
