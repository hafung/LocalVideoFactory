# 口播精剪

独立于「文案成片」的真人口播工作流。输入单个带原声的视频，不接收参考稿，不调用 TTS。录屏解说和多机位同步不在本阶段范围内。

## 工程隔离

- 使用 `talking-head-projects/<uuid>/project.json`，固定 `mode: talking-head` 和独立版本号；不修改已有 EditPlan。
- 独立 IPC、设置文件、任务、工程锁、预览模板和字幕展示。只有底层识别、分词、混音、渲染服务复用。
- 原片复制到工程中，剪辑是可撤销的源时间区间；字幕校正只影响显示文字。
- 原始识别 tokens、校正字幕和剪辑记录分别保存。原片与成片时间映射统一用于字幕、声音、画面和增强组件。
- TTS 模型准备状态不阻止口播模式使用，口播只检查自身需要的识别资源和媒体工具。

## 首次交付

导入 → 分段转写及缓存 → 静音与 VAD 共同确认的长停顿缩短 → 人工复核口头语建议 → 字幕校正与整句/逐字/逐词组展示 → 画面增强 → 预览及 MP4/SRT/ASS 导出。

只有获得静音和语音边界双重证据的停顿默认剪除；保留语音保护间隔。口头语建议不默认应用，不声称能识别所有犹豫音、结巴或重复起句。可以手动添加删除区间，并逐项恢复。自动剪辑目前使用规则，尚未接入语义模型判断表达意图。

画面增强先提供可编辑的重点卡片、手绘线框图解、本地素材全屏覆盖和画中画。增强关联原始语句，恢复剪辑后仍能正确定位。复杂图表、自由生成动画代码和自动视觉导演后续扩展。

字幕框允许纠错、删字、清空，以及用 `|` 指定短语分组；所有这些操作均不剪音视频。真正剪除内容需要在剪辑区域明确操作。新增或替换字符的内部显示时间可能是估计值，不作为自动剪辑的依据。

## 验收

- 未配置 TTS 时仍可导入、识别、剪辑、预览和导出口播。
- 修改或清空字幕后，剪辑区间、源 tokens、原片文件不变。
- 重叠删除只扣除一次时间；恢复删除后，音画、字幕和增强组件同步回到对应位置。
- 逐字/词组出现可独立选择高亮效果；预览和 ASS 共用显示状态，SRT 保留普通字幕。
- 取消任务不覆盖最后一个成功工程；重新启动可以恢复。
- 原有文案成片单元测试、类型检查、构建和字幕界面回归通过。

## 验证命令

先运行 `pnpm build`。使用 `VOXWEAVE_FFMPEG`、`VOXWEAVE_FFPROBE` 和 `VOXWEAVE_CHROME` 指定本机工具，执行 `pnpm smoke:talk`，会在 `.windows-smoke/talking-head` 生成识别结果、剪辑记录、字幕、截图和实际 MP4。默认使用仓库演示视频的声音，也可用 `VOXWEAVE_TALK_SMOKE_SPEECH` 指定至少四秒的口播音视频。

随后启动 Vite，使用 `VOXWEAVE_UI_URL` 指定服务地址（默认 `http://127.0.0.1:5178`），执行 `pnpm smoke:talk:ui`。该项使用浏览器桌面桥接样例调用真实字幕、剪辑和编译函数，验证字幕纠错、恢复剪辑、画面增强、模式切换及无 TTS 调用；不替代 Windows 安装包验收。

工作视频保留原画幅，标准化为 30 fps，最长边不超过 1920；工程另存原片。第一版不提供自动人脸避让、自由动画代码生成或语义级自动删改，贴图位置与剪点需在预览中检查。
